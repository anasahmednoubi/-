# إنجازاتي (Enjazati) - Task & Habit Tracker

تطبيق متكامل لتنظيم المهام والروتين اليومي ومتابعة التقدم والإحصائيات بدقة وتصميم مريح للعينين.

## المميزات الأساسية (Core Features)

1. **اليوم (Today)**:
   - مقياس تقدم تفاعلي بأنماط متعددة (مقياس دائري، حلقة كاملة، نصف دائرة، شريط أفقي، شرائح).
   - قائمة روتين اليوم ومهام اليوم مع متابعة الإنجاز اليومي واحتفال كنفيتي عند إتمام جميع مهام اليوم.
2. **مهام (Tasks)**:
   - إضافة وإدارة المهام المحددة بكميات (مثل قراءة صفحات، حفظ أجزاء).
   - شريط تقدم ملون حسب نسبة الإنجاز وتسجيل سريع للكميات المنجزة يوميًا وإمكانية التعديل والحذف.
3. **روتين (Routines)**:
   - جدولة العادات اليومية أو الأسبوعية أو أيام محددة من الشهر.
   - جدول أيام الأسبوع (من السبت إلى الجمعة) للمتابعة اليومية وإعادة الترتيب.
4. **إحصائيات (Stats)**:
   - تقارير أسبوعية وشهرية لنسبة الالتزام والنشاط اليومي.
   - تفاصيل إنجاز كل مهمة وروتين مع تقويم تفاعلي وتحديد العادة الأفضل والأضعف.
5. **المميزات المتقدمة الجديدة (New Features)**:
   - **نظام الأولوية (Priorities)**: تحديد أولوية المهام والروتين (منخفضة، متوسطة، مرتفعة) مع شارات لونية وفرز ذكي يضع الأولويات العالية أولاً.
   - **المهام المنتهية (Finished Tasks)**: قسم مخصص لعرض وأرشفة المهام المكتملة والتحكم في إظهارها أو طيّها.
   - **الإشعارات التحفيزية (Motivational Notifications)**: إشعارات تشجيعية دورية بفواصل زمنية مخصصة لتحفيز الاستمرارية.
   - **المزامنة السحابية وربط الحسابات (Firebase Cloud Sync & Auth)**: تسجيل الدخول الفعلي عبر حساب Google أو البريد الإلكتروني وكلمة المرور مع دعم استعادة كلمة المرور ومزامنة فورية للبيانات بين جميع أجهزتك عبر Cloud Firestore.
6. **المظهر والإعدادات (Settings & More)**:
   - الوضع الليلي والفاتح والتلقائي مع 8 ألوان مختلفة للتطبيق.
   - خطوط عربية ولاتينية متعددة والتحكم بحجم الخط.
   - نغمات صوتية Web Audio للإنجازات والتنبيهات.
   - دعم كامل للغتين العربية (RTL) والإنجليزية (LTR).
   - جولة تعريفية تفاعلية لكل قسم وحفظ البيانات محليًا وسحابيًا.

## التقنيات المستخدمة (Tech Stack)

- React 18 & TypeScript
- Vite
- Capacitor (Android Hybrid Wrapper)
- Firebase Auth & Cloud Firestore
- Web Audio API

## تشغيل وتثبيت التطبيق على الهاتف (Mobile App & APK)

### الطريقة 1: التثبيت الفوري كتطبيق هاتف (PWA) - بدون تحميل
1. افتح رابط التطبيق على هاتفك من خلال متصفح Chrome أو Safari.
2. اضغط على قائمة المتصفح (⋮) واختر **"تثبيت التطبيق" (Install app)** أو **"إضافة إلى الشاشة الرئيسية"**.
3. سيظهر التطبيق فوراً على شاشة هاتفك بأيقونته الخاصة ويعمل كتطبيق مستقل بدون شريط المتصفح وبشكل سريع جداً.

### الطريقة 2: بناء وتحميل ملف APK عبر GitHub Actions
ملف APK في نظام أندرويد يحتاج إلى كود مجمّع وموقع (`classes.dex` و `AndroidManifest.xml`). لذلك تم إعداد **GitHub Actions** تلقائيًا في المستودع:
1. ارفع المشروع إلى GitHub.
2. انتقل إلى تبويب **Actions** في صفحة المستودع.
3. اختر سير العمل **Build Android APK** واضغط **Run workflow**.
4. بمجرد انتهاء البناء (خلال دقيقتين)، ستجد ملف **Enjazati-APK** جاهزاً للتحميل المباشر وتثبيته على أي هاتف أندرويد.
