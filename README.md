# إنجازاتي (Enjazati) - Task & Habit Tracker

تطبيق متكامل لتنظيم المهام والروتين اليومي ومتابعة التقدم والإحصائيات بدقة وتصميم مريح للعينين.

## المميزات الأساسية (Core Features)

1. **اليوم (Today)**:
   - مقياس تقدم تفاعلي بأنماط متعددة (مقياس دائري، حلقة كاملة، نصف دائرة، شريط أفقي، شرائح).
   - قائمة روتين اليوم ومهام اليوم مع متابعة الإنجاز اليومي واحتفال كنفيتي عند إتمام جميع مهام اليوم.
2. **مهام (Tasks)**:
   - إضافة وإدارة المهام المحددة بكميات (مثل قراءة صفحات، حفظ أجزاء).
   - شريط تقدم ملون حسب نسبة الإنجاز وتسجيل سريع للكميات المنجزة يوميًا وإمكانية التعديل والحذف.
3. **روتين (Routines)**:
   - جدولة العادات اليومية أو الأسبوعية أو أيام محددة من الشهر.
   - جدول أيام الأسبوع (من السبت إلى الجمعة) للمتابعة اليومية وإعادة الترتيب.
4. **إحصائيات (Stats)**:
   - تقارير أسبوعية وشهرية لنسبة الالتزام والنشاط اليومي.
   - تفاصيل إنجاز كل مهمة وروتين مع تقويم تفاعلي وتحديد العادة الأفضل والأضعف.
5. **المظهر والإعدادات (Settings & More)**:
   - الوضع الليلي والفاتح والتلقائي مع 8 ألوان مختلفة للتطبيق.
   - خطوط عربية ولاتينية متعددة والتحكم بحجم الخط.
   - نغمات صوتية Web Audio للإنجازات والتنبيهات.
   - دعم كامل للغتين العربية (RTL) والإنجليزية (LTR).
   - جولة تعريفية تفاعلية لكل قسم وحفظ البيانات محليًا.

## التقنيات المستخدمة (Tech Stack)

- React 18
- TypeScript
- Vite
- Web Audio API
